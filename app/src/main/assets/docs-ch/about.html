一、关于本应用

1.1FreeFile 是一款面向进阶用户的 Android 双窗格文件管理器。它以双窗格与多标签为核心交互，通过统一的虚拟文件系统（VFS）同时管理本地存储、Root / Shizuku 高权限路径、压缩包内部以及 SMB / FTP / WebDAV / S3 等远程位置。

1.2除文件管理外，应用还整合了搜索与索引、压缩解压、文件加密、内置终端、Lua / Python 脚本、文本与富文本编辑、APK 逆向工具、媒体与 PDF 查看、内置浏览器以及 AI 文件管理助手。

1.3应用坚持本地优先：文件浏览、搜索索引与加解密均在本机完成；除用户主动配置的远程存储、局域网快传或 AI 服务外，不会主动上传文件内容。

三、主要能力

文件管理双窗格、多标签、批量重命名、回收站、多选、属性校验、视图与过滤。
高权限访问Root / Shizuku 自动探测与手动切换，记忆路径与引擎映射。
搜索索引深度、通配符、正则、内容过滤，可选后台索引缓存。
压缩与加密十余种压缩格式、包内浏览、加密 ZIP，以及独立的单文件 .cry 加密。
网络与快传WebDAV / FTP / SMB / S3，局域网 mDNS 发现与免流量互传。
终端与脚本真 PTY 终端、多会话、Root 模式，Lua / Python 文件 API。
编辑与查看文本 / 富文本编辑器、媒体查看器、PDF 查看器、内置浏览器。
逆向与扩展工具托盘、APK 启动器、虚拟容器，以及 AI 文件管理助手。

五、权限说明

所有文件访问浏览、复制、移动、重命名与删除共享存储中的文件。Android 11 及以上需在系统设置中手动授予。
Shizuku 权限在无 Root 时访问受保护目录。需用户主动安装、启动并授权 Shizuku。
安装与包查询解析 APK 信息、调用工具托盘与安装应用。
网络与 WLAN连接远程存储、局域网快传与 mDNS 设备发现。
前台服务保障文件传输、压缩解压等长时任务稳定运行。
相机 / 存储（按需）仅在内置浏览器上传、拍照等用户主动操作时请求。

5.1应用不会请求与功能无关的权限。详细的数据处理方式请阅读《隐私政策》。
