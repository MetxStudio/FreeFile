FreeFile 隐私政策

本政策说明 FreeFile 如何处理与保护您的信息，请在使用前仔细阅读

版本：v1.0 更新日期：2025-01-01 生效日期：同更新日期 MIT License
重要说明：FreeFile 是开源文件管理工具，核心文件管理功能以本地处理为主。 我们不会仅因您安装本应用而主动上传您的文件内容。若您使用需要联网的功能、第三方工具或第三方服务， 相关请求可能涉及必要的信息处理，具体以本政策说明为准。请在使用前阅读并理解本政策。
摘要：我们尽量遵循“最小必要”原则处理信息。文件浏览、复制、移动、删除、重命名、压缩、解压等核心操作通常在您的设备本地完成； 我们不会出售您的个人信息；您应谨慎处理敏感文件与权限；第三方组件与服务受其各自条款约束。

一、引言与适用范围

1.1本隐私政策（以下称“本政策”）由 FreeFile 项目作者/分发者（以下称“我们”）制定，用于说明您在安装、使用 FreeFile 应用（以下称“本应用”）过程中，我们如何收集、使用、存储、共享和保护相关信息，以及您享有的相关权利。

1.2本政策适用于 FreeFile 应用及其随附功能。本应用为开源项目，源码发布于 https://github.com/MetxStudio/FreeFile，采用 MIT License。开源代码的公开不等于您的个人信息或文件内容会被公开。

1.3本政策不适用于第三方组件、第三方服务或您通过本应用访问的第三方网站/服务。第三方有其独立的隐私政策，请您在使用前自行阅读。

1.4本政策与《FreeFile 用户协议》共同构成您使用本应用的完整约定。如本政策与用户协议在个人信息处理事项上存在不一致，以本政策为准。

二、定义

2.1“个人信息”指以电子或其他方式记录的与已识别或可识别的自然人有关的各种信息，不包括匿名化处理后的信息。

2.2“本地处理”指相关信息仅在您的设备上处理，未由我们主动上传至我们控制的服务器。

2.3“设备与运行信息”可能包括设备型号、操作系统版本、应用版本、语言设置、网络类型、IP 地址、请求时间、崩溃或诊断日志等，具体取决于实际功能与您使用的服务。

2.4“第三方服务”指由第三方提供、可能通过本应用调用或集成的网络服务、工具、库或组件。

三、我们处理的信息类型

3.1您主动选择处理的文件与路径信息。当您使用文件浏览、复制、移动、删除、重命名、压缩、解压等功能时，本应用需要访问您选择的文件、文件夹及其路径信息，以完成相应操作。此类信息通常在设备本地处理。我们不会仅因您安装本应用而主动上传您的文件内容。

3.2设备与运行信息。在您使用需要联网的功能、下载更新、访问第三方服务或发生错误诊断时，相关请求可能包含设备型号、操作系统版本、应用版本、语言、网络类型、IP 地址、时间戳及必要的日志信息。此类信息用于完成网络请求、保障服务安全、排查故障和改进兼容性。

3.3权限相关信息。为实现文件管理、网络访问、应用安装等功能，本应用可能请求存储/文件访问、网络、安装应用等系统权限。我们仅在实现相应功能所必需的范围内请求权限，您可以在系统设置中管理或撤销授权。

3.4您主动提供的信息。当您通过 GitHub Issue、邮件或其他方式联系我们时，您可能主动提供账号名称、联系方式、问题描述、日志或截图等信息。请您避免在公开渠道提交敏感个人信息、机密文件内容或他人个人信息。

3.5第三方组件产生的信息。本应用集成或调用的第三方库、工具或服务可能依据其自身隐私政策处理信息。我们建议您在使用相关功能前阅读第三方条款。我们不会控制第三方独立的个人信息处理行为。

3.6我们不会主动收集您的通讯录、短信、通话记录、精确位置、生物识别信息或健康信息，除非某项具体功能明确需要并在界面中另行说明并取得必要授权。

四、处理目的与处理原则

4.1我们处理相关信息的目的包括：提供文件管理与工具功能；完成您主动发起的操作；实现网络访问与第三方服务调用；保障应用与设备安全；排查崩溃、错误和兼容性问题；响应您的咨询、投诉或 Issue；遵守法律法规要求。

4.2我们遵循合法、正当、必要和诚信原则，尽量以最小必要范围处理信息。对于本地文件操作，相关信息通常在您的设备内完成处理，不必然传输至我们。

4.3在适用法律要求的情况下，我们处理个人信息所依据的合法性基础可能包括：您的同意；履行您作为一方当事人的合同所必需；履行法定义务所必需；应对突发公共卫生事件或紧急情况下保护自然人生命健康和财产安全所必需；在合理范围内处理您自行公开或其他已合法公开的信息；以及法律法规规定的其他情形。

4.4如我们需要将信息用于本政策未载明的其他目的，或将基于特定目的收集的信息用于其他目的，我们将依法另行告知并取得必要同意。

五、本地处理与网络传输说明

5.1FreeFile 的核心文件管理功能以本地处理为主。文件浏览、复制、移动、删除、重命名、压缩、解压等操作通常直接发生在您的设备上，相关文件内容不会仅因您安装或打开本应用而被我们主动上传。

5.2当您使用需要联网的功能时，本应用可能向相应服务器或第三方服务发送完成请求所必需的信息，例如请求地址、必要的参数、设备与网络信息、时间戳等。具体传输内容取决于实际功能。

5.3如您选择将文件上传、分享、发送至第三方服务或通过网络传输文件，相关文件内容及传输信息将由您主动发起，并可能受第三方服务条款和隐私政策约束。请您在传输前确认接收方、传输目的和数据的敏感性。

5.4互联网传输和存储并非绝对安全。我们将采取合理措施保护信息，但无法保证任何传输或存储方式绝对安全。请您避免通过不安全网络传输敏感数据。

六、设备权限说明

6.1文件/存储访问权限：用于浏览、读取、复制、移动、删除、重命名、压缩、解压您选择的文件和文件夹。拒绝授权可能导致相关文件管理功能无法使用。

6.2网络权限：用于访问网络、下载更新、调用在线功能或第三方服务。拒绝授权可能导致联网功能不可用。

6.3安装应用权限：如本应用提供应用安装或更新相关功能，可能需要安装应用权限。该权限仅在您主动使用相应功能时使用，您可以随时在系统设置中关闭。

6.4其他权限：如某项具体功能需要其他系统权限，我们会在相应界面或系统授权弹窗中说明用途。您有权拒绝或撤销授权，但可能影响对应功能的使用。

七、信息的共享、转让与公开披露

7.1我们不会出售您的个人信息。

7.2我们不会向第三方共享您的个人信息，除非存在以下情形：取得您的明确同意；为完成您主动发起的操作所必需；为提供您请求的第三方服务所必需；根据法律法规、司法或行政机关的强制性要求；为保护您、我们或他人的合法权益、财产安全或公共安全所必需；在涉及合并、分立、解散、被宣告破产等情形时，依法转移并继续受本政策约束。

7.3如涉及个人信息转让，我们会告知您接收方的名称和联系方式，并要求接收方继续履行本政策义务；接收方变更原处理目的或方式的，将依法重新取得您的同意。

7.4我们不会公开披露您的个人信息，除非取得您的单独同意，或法律法规另有规定。

7.5您通过 GitHub Issue 等公开渠道主动提交的信息可能被公众看到。请勿在公开渠道提交敏感个人信息、机密信息或他人个人信息。

八、信息存储地点与期限

8.1本应用的核心文件管理功能以本地处理为主，相关文件与配置通常存储在您的设备上。您应自行负责设备数据的安全与备份。

8.2对于因联网功能、诊断或您联系我们而产生的信息，我们将在实现处理目的所必需的最短期限内保存，法律法规另有规定或为处理争议所必需的除外。

8.3如相关信息无需继续保留，我们将依据适用法律采取删除或匿名化等措施。第三方服务存储信息的地点和期限以其隐私政策为准。

九、信息安全保护

9.1我们采取合理的技术和管理措施保护相关信息，防止未经授权的访问、泄露、篡改、丢失或滥用。例如，限制不必要的访问、遵循最小权限原则、及时处理安全问题和更新版本。

9.2请您妥善保管设备、账号和权限配置，避免在不受信任的设备或网络环境中处理敏感文件。如您发现安全风险或漏洞，可通过项目仓库联系我们。

9.3若发生个人信息安全事件，我们将依据适用法律及时采取补救措施，并在必要时向您告知事件情况、可能影响、已采取的措施及您可采取的防范建议。

十、您的权利

10.1在适用法律允许的范围内，您有权访问、更正、补充、删除您的个人信息，撤回同意，或要求解释说明本政策。

10.2您可以在系统设置中管理或撤销应用权限；如需行使其他权利，可通过本政策“联系我们”部分提出请求。我们将在核实身份后依法处理。

10.3撤回同意不影响撤回前基于同意已进行的处理活动的效力。若您撤回同意导致某项功能无法使用，相应后果由您承担。

10.4如您认为我们的个人信息处理行为损害了您的合法权益，您可向有管辖权的监管机构投诉或依法提起诉讼。

十一、未成年人保护

11.1本应用主要面向具备相应民事行为能力的用户。如您为未满 18 周岁的未成年人，请在监护人陪同下阅读本政策，并在取得监护人同意后使用本应用。

11.2监护人应指导未成年人正确使用文件管理功能，避免处理敏感文件、泄露个人信息或进行未经授权的操作。

11.3如我们发现在未取得监护人同意的情况下处理了未成年人的个人信息，将依法采取删除等必要措施。

十二、第三方组件与第三方服务

12.1本应用可能集成或调用第三方库、工具及服务。第三方组件受其各自的许可证、服务条款和隐私政策约束。

12.2第三方服务可能独立收集、使用或共享信息，我们无法控制其独立的个人信息处理行为。您在使用第三方服务前，应自行阅读并同意其隐私政策。

12.3对于第三方内容或第三方服务引起的隐私问题，请依据第三方提供的联系方式与其沟通；我们将在合理范围内提供必要协助。

十三、本政策的更新

13.1我们可能根据功能调整、法律法规变化或安全需求更新本政策。更新后的政策将在应用内或项目页面公布，并标明更新日期与生效日期。

13.2如更新涉及重大变更（例如处理目的、信息类型或共享方式发生实质性变化），我们将依法通过显著方式通知您，并在必要时重新取得您的同意。

13.3若您在本政策更新生效后继续使用本应用，即视为您已阅读并接受更新后的政策；如您不同意，应停止使用并卸载本应用。

十四、联系我们

14.1如您对本政策、个人信息处理或本应用隐私保护有任何疑问、意见、投诉或请求，可通过项目仓库 https://github.com/MetxStudio/FreeFile 提交 Issue，或联系项目维护者。

14.2为保护您的信息安全，我们可能需要核实您的身份后再处理相关请求。我们将在合理期限内予以答复。
