一、应用简介

1.1FreeFile（全能文件大师）是一款基于 Kotlin 与 Jetpack Compose 构建的 Android 双窗格文件管理器，集本地 / Root / Shizuku 文件访问、网络存储、终端、脚本、压缩解压、加密与逆向工具于一体。

1.2应用通过统一的虚拟文件系统（VFS）抽象层，让同一套复制、移动、重命名、删除等操作可以运行在本地分区存储、Root Shell、Shizuku、压缩包内部以及 SMB / FTP / WebDAV / S3 等远程位置。

1.3设计目标：在手机上提供接近桌面文件管理器的效率，同时保持界面清晰、操作可预期、危险操作有确认与撤销。

二、开始使用

2.1首次启动会展示功能弹窗，其中可阅读用户协议、隐私政策、本帮助与关于页面。点击“同意并继续”后进入主界面。

2.2建议按以下顺序完成初始化：

  1. 授予“所有文件访问权限”（Android 11 及以上需在系统设置中手动开启），用于浏览和修改共享存储。
  2. 如需访问 /data、/system 等受保护目录，可安装并授权 Shizuku，或为设备配置 Root。
  3. 进入“设置”检查访问引擎优先级、文件大小计算、多语言、搜索索引等选项。

2.3主界面为左右双窗格布局，每个窗格可打开多个标签页。触摸某个窗格即将其设为“活动窗格”，底部工具栏的复制、粘贴、删除等操作只作用于活动窗格。

2.4右侧窗格可通过顶部按钮临时隐藏或显示，便于在单窗格与双窗格之间快速切换；两个窗格也可一键交换位置。

三、文件管理

双窗格与多标签左右窗格独立浏览，标签会话可持久化，重启应用后恢复上次位置。
完整文件操作新建（支持 a/b/c 多级目录）、复制、剪切、粘贴、重命名、批量重命名与删除。
回收站删除默认先进入回收站，可恢复或清空；也可在确认后永久删除。
多选体系全选、反选、长按区间选择，配合操作面板批量处理。
属性面板查看路径、大小、时间、权限；目录可统计大小，文件可计算并持久展示 MD5 / SHA-256。
导航辅助面包屑、路径跳转、书签、最近目录、最近文件；每个列表固定提供 .. 返回上级。
三种视图列表 / 网格 / 大图标，支持按名称、大小、类型、时间排序并切换升降序。
细粒度过滤按文件夹、图片、视频、音频、压缩包、文档、代码、APK 等分类筛选，并可开关隐藏文件。

3.1复制、移动、解压遇到同名文件时，会提供“覆盖 / 跳过 / 保留两者”策略，并可选择批量应用，避免逐个确认。

3.2文件大小计算默认关闭，以加快大目录的浏览速度；需要查看目录占用时可在设置中开启，或在属性面板中手动统计。

3.3访问引擎默认按 Root > Shizuku > 本地分区存储 的优先级自动探测，并会记忆“路径前缀 → 引擎”的映射。也可以在设置中手动指定“自动 / Root 优先 / Shizuku 优先 / 仅本地”。

四、搜索与索引

4.1搜索支持配置递归深度：仅当前目录、指定层数或无限递归；支持通配符 * ?、正则表达式、完全匹配与区分大小写。

4.2可结合文件大小、修改时间与文件内容条件进行筛选，结果可直接进入所在目录或执行批量操作。

4.3开启“搜索索引缓存”后，应用会在后台建立索引，实现接近秒级的重复搜索；索引可在设置中随时关闭、清理或重建。索引仅保存在本机，不会上传。

五、压缩与解压

5.1支持格式：zip、jar、apk、7z、tar、tar.gz、tgz、tar.bz2、tar.xz、rar4、rar5、gz、bz2、xz。

5.2无需解压即可浏览压缩包内部：使用 xxx.zip#/内部路径 语法映射包内目录，像普通文件夹一样查看、复制或提取单个文件。

5.3加密 ZIP 解压时会要求输入密码；密码错误或文件损坏会给出明确提示，不会输出错误内容。压缩包密码与“文件加密”功能的密码相互独立。

5.4压缩时可选择目标格式与压缩级别；ZIP 格式额外支持设置密码与分卷大小（单位 MB，填 0 表示不分卷）。切换格式时目标文件扩展名会自动同步。

5.5大文件压缩 / 解压会在后台任务中执行并显示进度，完成后可直接跳转到输出目录。

六、文件加密与解密

6.1加密功能针对单个文件进行高强度保护，生成 原文件名.cry 文件；解密时选择 .cry 文件并输入密码即可还原原始文件名与内容。

6.2加密采用流式处理，避免一次性读取大文件造成内存溢出；密码仅用于派生密钥，不会以任何形式存储。

6.3密码错误或文件被篡改时，认证校验会失败，应用不会输出任何明文；请务必自行保管密码，密码丢失后无法恢复。

6.4加密完成后可选择删除源文件；受系统权限限制删除失败时，会提示您手动处理。

七、网络存储与局域网快传

7.1支持 WebDAV、FTP、SMB2/3、S3（兼容阿里 OSS 等 S3 协议端点），统一使用 remote:// 路径语法。网络位置可保存、编辑，并支持 SSL、域、Bucket、自定义 Endpoint 等配置。

7.2“局域网快传”基于 NanoHTTPD 与 mDNS 自动发现附近设备，无需数据流量即可互传文件，并保留接收记录。

7.3建议仅在可信的私有网络中开启快传；不要在公共 Wi-Fi 下开放服务，也不要将远程存储的账号密码告知他人。

八、内置终端与脚本引擎

8.1终端基于 Termux terminal-emulator 实现真 PTY + VT100，支持多标签会话、普通 / Root 模式以及自定义解释器路径（如 /system/bin/bash）。

8.2从文件列表打开终端时，可自动切换到目标目录并列出选中文件；终端运行于独立任务栈，可与文件界面自由切换。

8.3脚本引擎内置 Lua（LuaJ），并支持调用设备上的 Python 解释器。提供 freefile.list / read / write / copy / delete / mkdir / rename / exists / log 等文件 API。

8.4内置常用脚本包括列目录、存储信息、查找大文件、批量重命名预览、目录大小统计、删除空目录等，可作为编写自定义脚本的参考。

九、文本与富文本编辑

9.1文本编辑器支持搜索 / 替换 / 全部替换、正则、全词匹配、区分大小写、行号、跳转指定行、字号调节与多编码打开。

9.2超过 1 MB 的文件会自动进入“大文件流畅模式”并截断加载，避免编辑卡顿；如需完整编辑，建议在电脑上处理或先拆分文件。

9.3富文本编辑器支持 HTML / Markdown / 纯文本的编辑与格式互转，并可插入超链接。

十、逆向工具集

10.1“工具托盘”内置 APK 工具（Acode、APKToolM），可将当前文件直接传给工具，并按“解压 → 安装 → 启动”的流程处理。

10.2“APK 启动器”可解析未安装 APK 的包名、入口 Activity 与版本，并允许自定义启动 Intent（Action、Category、Data、Extras、窗口 Flags）。

10.3“VirtualBox 免安装运行”基于虚拟应用容器（Bcore），可将 APK 导入虚拟环境运行，无需安装到系统。

10.4逆向工具仅用于学习研究、个人文件处理及对自有应用的分析。请遵守当地法律法规与目标软件的许可协议，不要用于破解、篡改或侵犯他人权益。

十一、内置浏览器、媒体与文档查看

11.1内置浏览器支持多标签、地址栏、搜索、书签与页面内下载。网页触发的上传可选择任意类型文件并支持多选；HTTP 下载交给系统下载器，blob / data 链接由应用内桥接保存，页面底部会显示实时下载进度。

11.2图片支持双指缩放、双击放大与拖动；视频与音频使用 Media3 ExoPlayer 播放，媒体文件可在同一查看器中左右滑动切换。

11.3PDF 查看器提供页码跳转、缩放、分享与文件详情。查看器中删除文件后，结果会回传到主界面并刷新当前目录。

十二、AI 文件管理助手

12.1侧拉栏“文件管理 Agent”提供自然语言驱动的文件操作与问答。所有文件事实均由工具调用获取，模型不会凭空编造文件内容。

12.2任何写操作都遵循“预览 → 确认 → 执行 → 撤销”的闭环；批量操作超过 10 个文件时会先汇总确认。可在设置中单独授权某些操作默认允许。

12.3支持多会话、多标签、对话持久化与重命名，每个会话拥有独立上下文；支持接入第三方 MCP 服务器，并可记录 HTTP 请求日志。

12.4敏感目录、保险箱与加密容器默认不索引、不自动扫描；AI 生成的创作内容如需保存为文件，同样会走标准写操作确认流程。

十三、常见问题 FAQ

Q1看不到 Android/data 或 obb 目录？
请确认已授予“所有文件访问权限”，并在设置中将访问引擎设为自动、Root 或 Shizuku。Android 11 及以上普通分区存储无法直接访问部分系统目录。

Q2Shizuku 已安装但仍提示无权限？
需先在 Shizuku 应用中启动服务并授权 FreeFile；部分设备每次重启后需要重新启动 Shizuku。

Q3目录打开很慢或大小显示为“—”？
文件大小计算默认关闭。可在设置中开启，或仅对需要统计的目录使用属性面板，避免扫描超大目录。

Q4压缩包提示密码错误？
请确认压缩包确实加密、密码大小写与字符完全一致。本应用的“文件加密”密码与 ZIP 压缩包密码互不相通。

Q5删除的文件去哪里了？
默认进入回收站，可在侧拉栏“回收站”恢复或清空。若已选择永久删除，则无法通过应用恢复。

Q6终端没有输出或键盘异常？
请确认会话已创建且未被系统回收；可尝试新建会话、切换普通 / Root 模式，或在设置中更换解释器路径。

Q7如何切换语言？
进入“设置 → 语言”，选择简体中文或 English，应用会即时切换。Gallery 中的文档也可单独切换中英文版本。

Q8为什么网页下载没有出现在“下载”目录？
HTTP 下载由系统下载器保存到公共下载目录；blob / data 内容由应用写入下载目录。受分区存储限制时，文件可能位于应用专属的外部目录。
