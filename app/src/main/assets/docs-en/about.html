1. About the App

1.1FreeFile is an Android dual-pane file manager for advanced users. Built around dual panes and multiple tabs, it uses a unified Virtual File System (VFS) to manage local storage, privileged Root / Shizuku paths, archive contents, and remote locations such as SMB, FTP, WebDAV, and S3.

1.2Beyond file management, the app integrates search and indexing, compression and extraction, file encryption, a built-in terminal, Lua / Python scripting, text and rich text editing, APK reverse-engineering tools, media and PDF viewers, a built-in browser, and an AI file management assistant.

1.3The app is local-first: browsing, search indexes, encryption, and decryption all run on the device. It does not upload file contents unless you explicitly configure remote storage, LAN sharing, or an AI service.

3. Key Capabilities

File managementDual panes, tabs, batch rename, recycle bin, multi-select, property checksums, views, and filters.
Privileged accessAutomatic Root / Shizuku detection with manual override and remembered path-to-engine mappings.
Search indexDepth, wildcard, regex, and content filters with an optional background index cache.
Compression & encryptionMore than a dozen archive formats, in-archive browsing, encrypted ZIP, and standalone .cry file encryption.
Network & sharingWebDAV / FTP / SMB / S3 plus mDNS discovery and data-free LAN transfers.
Terminal & scriptingReal PTY terminal with multiple sessions and Root mode, plus Lua / Python file APIs.
Editing & viewingText and rich text editors, media viewer, PDF viewer, and a built-in browser.
Tools & extensionsTool tray, APK launcher, virtual container, and the AI file management assistant.

5. Permissions

All files accessBrowse, copy, move, rename, and delete files in shared storage. On Android 11 and later this must be granted manually in system settings.
ShizukuAccess protected directories when Root is unavailable. Requires the user to install, start, and authorize Shizuku.
Install & package queryParse APK information, use the tool tray, and install apps.
Network & Wi-FiConnect to remote storage, share files on the LAN, and discover devices via mDNS.
Foreground serviceKeep long-running transfers, compression, and extraction reliable.
Camera / storage (on demand)Requested only for user-initiated actions such as browser uploads or taking a photo.

5.1The app does not request permissions unrelated to its features. See the Privacy Policy for details on data handling.
